# Design and Development of a Cybersecure Decision Support System for Smart Hotel Operations

## Research Problem
*How can cybersecurity, operational data, and predictive analytics be integrated into a unified decision-support system to improve risk management and situational awareness in smart hotel operations?*

## Project Overview
This project presents a web-based decision support system designed for hotel management. The core innovation lies in bridging three historically siloed domains: **Industrial Engineering** (risk calculation, optimization, equipment maintenance), **Information Engineering** (Flask web framework, SQLite relational database, automated rules engines), and **Cybersecurity** (authentication log monitoring and anomaly detection).
